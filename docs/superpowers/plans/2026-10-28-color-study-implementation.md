## 1. 执行方式

先打通最小真实路径，再增加自动更新和 AI，不从漂亮但无内容的首页开始。

主路径：

**一条经核实的外部教程 → 可访问的原片获取入口 → 本地资料与预览 → 可选练习结果 → 当前页面 AI 提问。**

每阶段有独立退出条件。未通过的关口记为未完成，不用模拟数据或模型生成的教程冒充完成。计划不承诺固定日历工期，按验收推进；若来源、许可或用户 API 访问构成阻碍，报告具体阻碍和可继续的工作，不扩大已批准范围。

### 阶段依赖

| 阶段 | 交付 | 前置 |
| --- | --- | --- |
| P0 | 内容与原生依赖的可行性检查 | 用户批准文档 |
| P1 | 本地应用骨架、数据库与安全底座 | P0 技术检查 |
| P2 | 教程库与资料页的完整人工路径 | P1 |
| P3 | 媒体、色彩速查与可选练习记录 | P2 |
| P4 | RSS/Atom 发现流 | P2；可与 P3 并行 |
| P5 | 可配置 AI 与页面上下文 | P1–P3 |
| P6 | 备份、恢复与数据生命周期 | P2、P3、P5 的数据结构稳定 |
| P7 | 真实内容、浏览器回归与交付 | P3–P6 全部通过 |

P0 的素材核查可在后续非依赖工作中继续，但至少确认一条风光、一条人像配套跟练入口后，才将产品作为真实学习预览交付。最终全部内容指标在 P7 验收。

## 3. P0：实施前检查与首批内容取样

### 工作

1. 确认新目录仍只有文档，记录 Node 24、npm、系统架构和未占用的本地端口。
2. 创建最小依赖探针，验证 better-sqlite3 的事务与迁移、sharp 对 JPEG/PNG 的转换、钥匙串库在 macOS arm64 的读写删除。
3. 钥匙串探针只使用随机测试凭据，明确 service/account 前缀，完成后只删除该测试项。不读取用户已有凭据。
4. 验证失败时先定位版本与二进制兼容问题，不降级为明文保存 Key，不全局安装工具，也不更换主技术栈而不说明。
5. 为风光、人像各找一条真实 Photoshop/Camera Raw 教程候选，核对实际教学片段、原片对应关系、下载条件和个人使用许可。
6. 寻找两个实际可读取的摄影/机构 RSS 或 Atom 地址。必须来自来源页面明确公布或可验证的订阅入口，不猜测 `/feed` 等地址并当成已接通。
7. 逐条建立来源调查表：原始链接、查看范围、许可、素材、版本、访问限制、检查结果。候选仍是候选，不能写成推荐。

### 验收

- 三种原生/本地关键依赖完成实际探针，未污染用户其他项目。
- 记录至少两条配套跟练入口及其证据，或明确报告哪条未满足；未满足的不会被正式种子数据接受。
- RSS 真实响应与许可检查分开记录；可读取不自动授权复制图片。
- 没有为了内容指标购买课程、绕过付费墙或批量下载陌生图片。

### 依赖风险的确定处理

如果某个候选无法取得正文或 RAW，选择替代候选；如果目标摄影师没有开放订阅，降为手动收藏，不开发绕过限制的爬虫。若最终免费配套素材不足，先向用户说明，不能自行改为收费依赖。

## 4. P1：本地骨架、数据库与安全

### 工作

1. 在新目录创建 npm workspaces：web、server、shared；配置 TypeScript、Vite、Tailwind、Hono 与测试工具。
2. 开发模式由 Vite 代理 `/api`；生产由 Hono 同源托管构建产物。启动命令只绑定 127.0.0.1。
3. 约定生产默认端口 4317，开发前端 5173；端口占用时明确报错，不偷偷扩大监听地址或跳转陌生端口。允许由本地启动配置显式修改。
4. 只允许实际配置的 Host 和 Origin。对写入、AI 请求和连接测试要求 CSRF 令牌；不设置通配 CORS，不提供可由跨站页面读取的凭据接口。
5. 创建用户数据目录、SQLite 迁移机制、外键约束与安全文件访问。数据库执行参数化查询。
6. 建立统一可读错误结构：错误码、可展示消息、可重试标志、请求 ID；日志不记录 Key、完整 AI 请求正文或用户图片。
7. 完成 UI 外壳：导航、空状态、全局错误、键盘焦点与窄屏布局，不填入假教程。

### 验收

- 启动、刷新、关闭重开正常；生产构建无需同时运行 Vite。
- 未配置 AI 也能进入主界面。
- 非法 Host、恶意网站 Origin、缺失或错误 CSRF 的写入请求被拒绝；合法页面路径正常。
- 任意文件绝对路径与 `../` 无法通过资产 API 访问。
- 数据写入失败返回可理解错误，不留下半条记录。

## 5. P2：教程库与人工整理路径

### 工作

1. 按规格实现 Source、Tutorial、TutorialSection、QualityReview、标签与收藏数据结构；审核状态、访问状态、原片配套状态独立。
2. 提供手动添加与修改教程：URL、作者、主题、工具、难度、语言、版本、访问条件、摘要和来源证据。未知信息允许为空。
3. 完成筛选、组合搜索、收藏、最近打开和详情页。首版用 SQLite 查询完成检索，不引入向量库。
4. 实现审核表单与记录展示。审核依据只有元数据时，不允许直接标为推荐；系统不设置虚假的实测复现状态。
5. 章节只录入有依据的标题/时间点/选段；没有章节时展示原站按钮，而不是自动生成教学步骤。
6. 按允许条件使用官方嵌入；不支持时保留正常外链。渲染摘要和 Markdown 时禁用原始 HTML 与脚本 URL。
7. 建立作品与教程关联，但不将关联的摄影作品自动标为配套目标图。

### 验收

- 从空库添加一条真实教程，搜索到它、收藏、打开详情与原站，再重启仍保留。
- 同一规范 URL 重复录入时提示已有记录，不生成重复课程。
- 没有原片、没有正文、需要登录或付费的状态准确。
- 原站拒绝嵌入不影响打开链接；外链与当前页 AI 状态相互独立。
- 作者名、摘要、来源文本里的 HTML/脚本不被执行。

## 6. P3：媒体、知识卡和练习资料

### 工作

1. 实现资产导入：JPEG/PNG、RAW 不透明副本；哈希、大小、来源、许可、角色与教程对应关系登记。
2. 按规格的文件与解码上限校验，上传先进入临时区，校验成功再提交数据库与文件索引；失败清理本次临时产物，不删除用户原文件。
3. RAW 不解码、不自动生成 JPEG；允许关联单独的合法预览。UI 明确“RAW 无预览”，仍可导出本地保存的原片副本。
4. JPEG/PNG 生成固定参数的缩略图、sRGB 工作预览、主色盘和显示亮度分布。没有处理权不运行统计。
5. 使用确定性的中位切分算法取色，最多六色；保存图像哈希、派生参数和分析版本。透明像素不参与统计。
6. 实现知识卡、引用来源、工具关联及 HSV 色轮。互补示意 H+180°，类似色默认 ±30°，分裂互补默认 H+150°/H+210°，均明确只表示该色相环上的配色关系。
7. 实现可选 Practice、自由笔记和导出版本；基础并排查看只用于资料回看，高级滑动差异比较留后续。
8. 对资产移除先解除关联；要删除托管文件时展示其他引用和影响并确认，不因删一条笔记误删共享原片。

### 验收

- 导入许可样片 RAW 后文件哈希不变，原始本机文件未被移动或改写。
- 无预览、格式不支持、损坏、超大图片与磁盘写入失败均有明确反馈。
- 相同输入与分析版本产生相同结果；统计注明基于哪张预览，不把显示亮度当 RAW 曝光。
- 只有来源链接、没有图片使用依据的作品不产生缓存预览或色盘。
- 色轮 0° 的互补为 180°，跨 360° 正确环绕；正文解释 RGB/HSV 与 RYB 不是同一套规则。
- 自由笔记可为空；保存作品不会触发考试、强制复盘或“掌握”判断。

## 7. P4：订阅来源、发现流和缓存

### 工作

1. 创建来源设置：明确 URL、类型、启用状态、许可、抓取间隔与最后成功/失败信息。
2. 抓取器与解析器分离。限制单响应 2 MiB、网络等待 15 秒、至多三次重定向；每一步校验目标地址与实际连接，防止 SSRF 和 DNS 重绑定。
3. 不允许来源请求访问本机、内网或云元数据地址；AI 本地服务例外不能复用到内容抓取。
4. RSS/Atom 解析不执行 HTML，不处理外部实体或 DTD。保留来源 GUID 与原始 URL。
5. 规范 URL 只去除已知追踪参数，不删除可能决定资源身份的查询参数；章节定位另存。按 GUID/规范 URL 精确去重，保留来源出现记录。
6. 实现每 6 小时调度、启动超期补查、ETag/Last-Modified、同源防重入和失败退避。手动刷新同源最短间隔 60 秒。
7. 发现流只展示候选条目；收藏与推荐是用户行为。获准图像才可交给 P3 生成观察卡。
8. 移除订阅不删除已有收藏，缓存失败不清空上一版可用数据。

### 验收

- 两个真实来源能被读取；本地固定响应测试覆盖 RSS、Atom、304、重复 GUID、同 URL 多来源。
- 同一批数据连续更新三次，条目数量不增加，来源记录不丢失。
- 断网、403、429、无效 XML、过大响应、重定向到内网不会造成持续高频请求或整个服务退出。
- 服务停止时不宣称持续更新；重启只补一次，并显示实际更新时间。
- 订阅读取成功但图片无授权时保持文字卡，而不是默认下载图片。

## 8. P5：AI 服务、页面上下文与答疑

### 工作 A：配置与服务端协议

1. 创建 ProviderConfig 和钥匙串凭据适配。前端只能获取配置摘要与 hasKey；修改 Key 后清除输入，不写入 localStorage/IndexedDB。
2. 校验 Base URL 的 scheme、host、port、userinfo、query、fragment 和路径前缀；只对显式 loopback 服务放开 HTTP。禁止带凭据的自动重定向。
3. 创建测试连接操作：需用户点击，提示会发出一次最小请求并可能计费，不附页面上下文。
4. 实现兼容 Chat Completions 请求；默认最小字段，按配置二选一发送输出限额参数。供应商不支持时明确报告，不自动更换参数反复试请求。
5. 上游通过 fetch/流式读取，前端通过 POST fetch 接收本地 SSE。正确处理 UTF-8 跨块、事件分隔、空 delta、结束标记、错误与输出长度达到上限。
6. 连接/首字节等待上限 30 秒，流式空闲上限 30 秒，整次请求最长 180 秒；超时可由用户重新发起，但不自动重试。

### 工作 B：上下文和会话

1. 定义 ContextItem：类型、原始出处、定位、实际文本或受控资产 ID。禁止从客户端提交任意本地路径或让模型指定读取位置。
2. 前端在发出前列出当前页面、实际段落、选中文字、软件工具信息、附件与历史范围，提供移除操作。
3. 浏览器把选择提交给后端；后端验证这些资料属于当前本地内容且可发送，形成不可变的请求快照。之后页面导航不改变已发请求。
4. 历史默认最近六轮并明示范围；上下文、历史和问题合计 12,000 Unicode 字符，输出默认 1,024 token。超限阻止发送并指出需要删减的项，不静默截断。
5. 按规格处理最多两张明确选择的派生图，移除位置等 EXIF，不上传 RAW；不支持图像时禁止带图发送但保留文本使用。
6. 配置不可信材料隔离、引用编号白名单、一般建议标签；模型没有工具调用能力。无法取得正文时在 UI 和请求中都标注缺失。
7. 请求绑定 conversationId/requestId/pageContextId；取消同时取消上游。已收到部分内容可保存为 interrupted，不能标 complete。
8. 旧请求留在原会话；切换页面后进入对应会话。用户可清空会话，但删除需确认，并正确处理只被该会话引用的附件。

### 工作 C：界面

完成常驻入口、侧栏/窄屏抽屉、消息流、上下文预览、模型标识、发送/取消、错误提示和来源定位。“询问选中文字”只预填，不自动发送。侧栏不是课程步骤控制器，不更改原教程。

### 验收

- 无 Key、钥匙串锁定、连接失败时，教程与本地资料功能不受影响。
- 使用模拟兼容服务测试文本成功、图片成功、401、429、超时、非法 SSE、上下文超限、输出截断和取消。
- 发送前选择与实际请求上下文一致；取消 A、切到 B 后，A 的输出不能进入 B。
- 没有正文的教程提问不会声称已经读过完整视频；只有允许的引用 ID 能变成来源链接。
- 恶意教程片段不能让助手读取 Key、上传其他文件或改变服务地址。
- 浏览器存储、响应、日志、备份和上下文快照不含 Key。用户主动输入到普通笔记的其他敏感内容仍需用户自行判断，不声称能自动识别所有隐私。
- 用户配置实际服务后，经明确同意执行一条文本真实请求；图像支持另测。没有真实 Key 时，记录为“模拟合同测试通过，真实接入待用户验证”，不能整体冒充真实验证通过。

## 9. P6：备份、恢复与数据生命周期

### 工作

1. 使用 SQLite 一致性快照，而非在运行中直接复制单个数据库文件。
2. ZIP 备份包含版本、数据库、托管资产、大小与哈希清单；使用流式读写，避免把全部 RAW 装入内存。排除 Key、日志、临时文件与依赖目录。
3. 备份时固定一致的数据库/资产视图，资产为不可变文件；暂停实际文件清理直到快照完成，避免引用存在但文件已删。
4. 恢复到新目录，验证模式版本、条目路径、符号链接、重复路径、声明与实际展开大小、哈希及磁盘空间。拦截路径穿越和压缩炸弹。
5. 用户确认后切换有效数据目录，保留原目录供回退。无效包或取消不改当前数据。
6. 显示备份可能包含私人人像、聊天与笔记，默认不宣称已加密。恢复后没有 Key，提示重新配置。
7. 升级迁移前生成本地回退快照；迁移失败不丢失旧库。不同版本不兼容时拒绝恢复并说明支持范围。

### 验收

- 持续写笔记时生成的备份可以在独立测试目录恢复，关联、版本、图像哈希一致。
- 缺文件、哈希错误、过新版本、恶意路径和空间不足都不会覆盖现有库。
- 恢复后的教程/笔记/图像可用，AI Key 不出现且需重新配置。
- 删除记录或迁移失败均不会改写用户最初导入文件所在位置。

## 10. P7：真实内容、回归与交付

### 内容验收

- 8 条推荐教程：风光 3、人像 3、通用工具 2。
- 至少风光、人像各 1 条配套 RAW 已核对对应关系、获取条件与个人使用依据。
- 12 张有真实来源的知识卡，覆盖用户不熟悉的曲线、HSL、蒙版和配色概念。
- 2 个真实可读的摄影/机构订阅来源，注明授权边界与最后检查时间。

## 11. API 与数据契约的实现清单

路径在实现时保持单一风格；下列是首版需要覆盖的接口职责，不是已存在的接口。

| API 组 | 必需职责 |
| --- | --- |
| `/api/session` | 同源会话初始化和 CSRF，不能泄露凭据 |
| `/api/tutorials` | 查询、创建、更新、详情、章节、收藏与审核记录 |
| `/api/library` | 摄影作品、标签、收藏及教程关联 |
| `/api/assets` | 安全导入、元信息、受控预览/原文件导出、关联和移除 |
| `/api/practices` | 可选笔记、所用素材、导出版本 |
| `/api/knowledge` | 知识卡、来源、工具与关联教程 |
| `/api/sources` | 来源配置、手动刷新、状态、候选条目 |
| `/api/ai/config` | 非敏感配置、保存/删除钥匙串凭据、测试连接 |
| `/api/ai/conversations` | 页面会话、消息、实际发送上下文记录 |
| `/api/ai/chat` | 一次 POST 流式请求及取消，校验预算和权限 |
| `/api/backups` | 生成、导出、验证、确认恢复，排除凭据 |

重要事务：教程配套关系与证据一起提交；素材导入只有文件验证成功才入正式库；用户消息与发送快照同事务创建；完成/中断状态由实际上游事件决定；恢复切换前不动旧库。
