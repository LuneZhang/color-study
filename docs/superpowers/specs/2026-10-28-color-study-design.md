# 调色书房：产品与技术规格

- 日期：2026-10-28
- 工作名称：调色书房（Color Study）；名称不影响功能，可在开发前调整。
- 状态：历史规格。描述的是本地服务原型，已被 2026-10-28 的 GitHub Pages 静态站点重构取代。当前设计见[静态站点重构说明](../../2026-10-28-static-redesign.md)。
- 实施计划：[实施计划与验收清单](../plans/2026-10-28-color-study-implementation.md)
- 部署边界：macOS 本机、单用户、浏览器访问，Photoshop + Adobe Camera Raw 中实际调色。

## 1. 产品定位与成功标准

这是一个以外部优质教程为中心的个人调色学习资料站，不是 AI 自动教程生成器，也不是带强制关卡的课程系统。

目标用户的主要题材是风光旅行和日常人像；已会曝光、白平衡、高光阴影等基本调整，但不理解曲线和 HSL 原理，尚不会熟练操作蒙版。产品帮助用户找到值得学习的作品与教程、获取真正配套的原片、随时查概念，并用页面联动 AI 回答学习中的具体疑问。

核心路径：

**发现作品或目标效果 → 找到优质外部教程 → 获取作者配套原片 → 在 Photoshop / Camera Raw 中跟随作者操作 → 可选保存练习结果与笔记。**

学习中随时可以问 AI，但 AI 不替代作者的完整教学。

首版成功标准：

1. 用户能区分“只有作品可欣赏”“有完整教程”“有教程且有配套原片”。
2. 至少能找到风光、人像各一条经过内容质量检查、实际核对原片获取条件的跟练入口。
3. 曲线、HSL、互补色、蒙版等常见疑问能通过有来源的知识卡或关联教程解决。
4. 配置兼容 AI 服务后，可以在当前教程页面提问，且清楚知道发送了哪些资料。
5. 没有 AI、离线或某个外链失效时，已有收藏、笔记和本地文件仍可使用。

## 2. 已确定的产品原则

### 2.1 教学归作者，筛选与组织归站点

- 保留外部教程原有的步骤、原理和调色思路，不自行改编为站内课程。
- 不根据原片与成片推断摄影师真实参数或完整后期流程。
- 不设置预测题、强制复盘、六步训练、打卡解锁或自动“已掌握”评价。
- 可以显示原教程章节、时间点和依法取得的选段；不能凭标题编造章节或引用。
- 质量审核不要求把每课重新操作一遍，也不因此宣称“已实测复现”。
- AI 可以解释原理、比较工具、提出有条件的操作建议；不能把自己的建议冒充作者原话。

### 2.2 四类内容不混淆

| 类型 | 可以提供什么 | 不可以暗示什么 |
| --- | --- | --- |
| 摄影参考作品 | 来源、作者、收藏、获准图像的色彩观察 | 已知道作者的后期流程 |
| 外部教程 | 原站入口、内容摘要、工具与难度、审核依据 | 站点拥有完整视频或再分发权 |
| 配套练习素材 | 作者提供的原片入口及其与教程的对应依据 | 任意同题材 RAW 都是该教程原片 |
| 独立 RAW 素材 | 有许可的下载与个人练习机会 | 自动附带完整教程或标准答案 |

### 2.3 自用、低维护、可退出

不做云端、多用户、社交、付费系统或复杂课程后台。数据可备份与恢复，不与某家 AI 服务绑定。默认不开机自启；只有本地服务运行时才进行订阅更新。

本文“离线”指本地服务保持运行、外网断开；本地服务停止后不保证页面或 API 可用，首版不实现停服后的离线应用。

## 3. 首版范围与明确不做的事

### 3.1 首版必须包含

- 中文界面的首页、教程库、作品库、色彩速查、练习资料、设置。
- 教程搜索、主题筛选、收藏、手动录入、质量审核记录、原站访问。
- 来源与许可登记、原片获取入口、本地 RAW 文件导入、JPEG/PNG 预览与练习导出图版本。
- RSS/Atom 白名单来源定时更新、手动刷新、去重、失败状态和缓存。
- 获准图像的主色盘、显示亮度分布；有来源说明的色轮与配色速查。
- 可选的自由笔记和练习结果保存，不强制完成任何学习流程。
- 可配置的 AI 服务、真实文本流式对话、页面上下文、可选图像附件、取消与错误恢复。
- 备份、恢复、凭据保护、可操作的空状态与离线状态。

### 3.2 后续再考虑

- 单个经过授权、确有价值的非 RSS 页面适配器。
- 原片与导出图的高级滑动对比、局部放大同步、差异可视化。
- 更多 AI 原生协议、多个服务配置、专业图像分析。
- 更大的知识检索库、自动内容初筛与批量辅助标签。
- 桌面封装、开机自启、云端访问、跨设备同步。

首版不做通用爬虫、视频下载与自动转写、浏览器扩展、Photoshop 插件、浏览器 RAW 显影、自动 XMP 生成与回写、AI 自动代调照片、向量数据库、任务队列集群或自动审美打分。

## 4. 页面与交互

### 4.1 首页

首页是资料入口，不是课程引导器。依次呈现最近打开的教程、收藏中的可跟练教程、订阅新内容和常用知识入口。没有数据时展示真实的添加教程、添加来源和配置 AI 操作，不使用虚构作品填充正式库。

### 4.2 教程库

筛选维度：风光/人像/通用基础、Photoshop/Camera Raw/其他软件、曲线/HSL/蒙版等工具、入门/进阶、语言、免费/登录/付费、是否有配套原片、审核状态。

默认搜索已收录内容，不假装执行全网实时搜索。外部教程优先人工挑选，RSS 条目只进入候选队列。Lightroom 教程可单独标为迁移参考，不冒充 Camera Raw 的完全同界面教程，也不计入首批 Camera Raw 跟练覆盖。

列表明确显示标题、作者、题材、主要工具、素材状态、访问条件与最后检查时间。不知道的软件版本、时长或发布日期留空并显示“未注明”，不由模型补猜。

### 4.3 教程详情与练习资料

详情包含作者原文链接、真实可用的嵌入播放器或外链按钮、摘要、工具与前置知识、配套原片入口、版本说明、审核记录、相关参考作品和可选笔记。

只有来源允许嵌入且技术上支持时才嵌入，否则在新标签页打开原站。首版不承诺同步第三方视频播放进度；章节由已核实的索引或用户手动定位。

原片下载默认在来源站完成；用户随后用文件选择器将合法持有的文件导入本地资料库。导入保存副本，不移动或改写用户原文件，并提示额外磁盘占用。RAW 无预览时仍可管理；用户可另外导入 Camera Raw 导出的 JPEG/PNG。

练习记录仅包含关联教程、所用原片、可选自由笔记、导出版本、更新时间与用户手动状态。不同照片之间不计算像素相似度，也不以相似度判断是否调得好。

### 4.4 作品库与发现流

按作者、来源、题材、收藏和是否关联教程浏览。作品与教程关联允许一对多，但关联关系不能写成“作者真实复刻方法”，除非来源明确表明对应关系。

无图片复制依据时显示文字卡和原链接。获准处理图片后才显示缓存预览与观察卡。原图的使用权、缩略图的使用权、分析处理权分别记录。

### 4.5 色彩速查

首批知识卡覆盖：

- 曝光、高光/阴影、对比度、白平衡、配置文件与版本差异。
- 明暗曲线与 RGB 通道曲线的区别。
- HSL 色相、饱和度、明亮度；颜色混合器与局部蒙版的区别。
- 自然饱和度与饱和度、颜色分级、点颜色的适用语境。
- 色轮互补、视觉对立色、软件色轴不是同一个概念。
- 风光中的植被与天空、人像中的肤色与环境色，作为查找教程的主题，不给统一配方。

每卡只有概念、适用语境、常见误解、可靠来源和相关教程，不生成新的整套调色课程。中文说明保留软件英文术语，方便对照界面；关联 AI 的“询问这个概念”只预填上下文，不立即发出请求。

交互色轮第一版采用明示的 HSV 色相环：互补配色示意取 H+180°，保持 S/V。它不是 RGB 三通道数值反相，也不代表颜料混色的 RYB 规则。类似色与分裂互补色也明确所用角度。人像肤色不设统一标准数值。

### 4.6 AI 侧栏

较宽窗口使用可展开侧栏，窄窗口改为抽屉；不挤占主要照片区域。视觉上区分“作者教程”“来源知识”和“AI 回答”。切换页面可保留侧栏，但新请求使用新页面会话；已发请求仍归原会话，不把输出写进另一课。

预览图片周围使用中性灰表面，避免大面积高饱和背景影响观感。字体、键盘焦点和状态信息优先可读性；色块同时显示数值和文字，不只靠颜色区分。

## 5. 内容准入、质量与来源更新

### 5.1 教程质量审核

使用结构化证据，不使用不透明的百分制评分。

| 检查项 | 审核关注点 |
| --- | --- |
| 来源可信 | 作者与原始页面可追溯；转载指向原作者 |
| 教学实质 | 有实际操作展示，不只是前后效果或预设广告 |
| 原理与取舍 | 能解释至少主要操作的理由，而非只列参数 |
| 过程连贯 | 可观察到主要处理过程；缺失或无法查看的部分明确记录 |
| 素材对应 | 声称配套时，教程与 RAW 的对应关系有证据 |
| 适用条件 | 软件、版本、语言、难度、访问要求已记录或明确未知 |

每条审核记录保留：检查时间、检查者类型、实际看过的范围（元数据/选段/教学内容）、每项结论、简短依据与来源定位。

仅凭标题、作者名、点赞量或模型猜测不能成为推荐。只检查到简介的内容仍是候选。访问不到全文或视频不绕过登录、付费或反爬；需要用户自行访问或换来源。

“质量通过”与“原片已配套”独立显示。首版不提供“本站已实测复现”徽章。用户保存一次练习结果也不会改变教程审核状态。

### 5.2 许可与使用

默认只收录必要的出处元信息和原链接，不镜像外部视频、全文或整套 RAW。RSS 可访问、robots.txt 允许、来源标注作者均不等于图片复制授权。

许可记录区分正文引用/缓存、图片复制、图像分析、原片个人使用、再分发；未说明的权利记为未知。用户自己拍摄的素材登记为自有作品；第三方素材记录原始来源和许可依据。人像的版权许可不自动等于模特肖像授权，不把个人学习素材随意公开或用于商业用途。

### 5.3 定时更新规则

- 来源必须由用户或首批内容整理明确添加；不抓取整个互联网。
- 首版只保证 RSS/Atom 协议能力，不保证某位摄影师必定提供开放订阅。
- 默认每 6 小时检查一次，提供手动刷新；连续手动刷新设置短间隔保护。
- 启动或检测到超期后补一次，不补跑关机期间每个时段。
- 源内 GUID 与规范 URL 去重，保留原始链接及来源记录；不按相似标题自动合并。
- 使用 ETag/Last-Modified，304 不重复处理；定时任务同源防重入。
- 失败保留旧数据，分别显示最后尝试与最后成功时间；下次失败重试间隔递增，最大 24 小时，不在短时间内反复请求。
- 来源下线不删除已收藏条目。过期、付费或原片链接失效不会伪装为正常可用。

## 6. 图像与 RAW 的能力边界

### 6.1 RAW 不在浏览器中显影

不假设 sharp 或浏览器能解码所有相机 RAW。首版将 RAW 作为不透明本地资产保存与导出，记录格式、大小与哈希。预览来自用户或来源有权提供的 JPEG/PNG，必须标明来源，不冒充当前 RAW 的准确渲染。

实际调色在 Camera Raw 完成。站点不读取滑块、历史记录、屏幕或打开的照片；也不自动写 XMP。Camera Raw 的配置文件、处理版本、白平衡与原始文件差异可能改变显示结果，教程元信息需保留这些已知条件。

### 6.2 本地观察卡

对允许处理的 JPEG/PNG：统一方向，转换到 sRGB 派生图，固定采样算法和版本，提取最多六个主色及近似占比，生成显示亮度分布。原文件不被覆盖。

统计基于当前预览的像素，不是 RAW 曝光读数，不代表语义主体、真实光源色温、皮肤健康状态、作者思路或审美质量。冷暖关系仅作有明确规则的辅助文字，不输出一个被当作标准的“冷暖得分”。图片过小、损坏或无法转换时隐藏统计并说明原因。

初始文件边界：JPEG/PNG 单文件不超过 50 MiB、解码不超过 100 百万像素；RAW 单文件不超过 512 MiB。超出时明确提示，不自动压缩或截断原片。缩略图最长边 480 px，工作区预览最长边 2560 px，统计采样最长边 512 px；参数写入分析版本，便于复算一致。

## 7. AI 配置、上下文与回答约束

### 7.1 首版协议

支持一个当前启用的 OpenAI 兼容 Chat Completions 配置：显示名、Base URL、模型 ID、是否支持图片、输出上限及对应的限额参数类型。Base URL 是 API 前缀，服务端追加 `/chat/completions`，不把普通网站首页视为接口。

兼容模式默认使用 `max_tokens`；明确要求新字段的服务可选择 `max_completion_tokens`。不同时发送两个字段，不默认发送 temperature、工具调用或供应商特有选项。接口支持范围按实测标注，不承诺任意模型兼容。

文本连接测试与图片能力分开：文本成功不能证明支持图片。测试会明确提示可能产生一次 API 费用，只发送最小测试内容，不附带页面或照片。用户 API Key 只在本机设置界面输入，不要求粘贴到开发会话。

### 7.2 凭据与网络

Key 由后端通过 macOS 钥匙串保存，数据库只存非敏感配置和凭据引用。候选依赖为 `@napi-rs/keyring`；截至本轮 npm 元信息显示 2.1.2 且提供 darwin-arm64 包，仍需开发阶段实际验证。

保存后 API 只返回是否已配置，不返回完整 Key。浏览器不持久化输入值；日志、错误、AI 上下文及备份中均不包含凭据。钥匙串不可用时提示修复并停用 AI，不静默落盘为明文。

远端服务要求 HTTPS；仅用户显式配置的 localhost、127.0.0.1 或 ::1 服务允许 HTTP。禁止 URL 用户信息、查询参数和片段携带密钥，禁止自动跨域重定向转发凭据。普通内容来源不拥有修改 AI 地址或参数的能力。

### 7.3 上下文包

每次发送前可见、可移除的上下文项包括：

1. 页面类型、内容 ID、标题与原始来源。
2. 当前实际可用的知识卡或教程选段及其出处定位。
3. 用户选中的文字或明确选择的章节。
4. 用户填写的软件与当前工具信息；缺失时保持未知。
5. 用户主动附上的截图或 JPEG/PNG 派生图。
6. 本会话最近至多六轮对话；界面显示本次包含范围，更早记录仍在本地但不默默发送。

打开或切换页面只准备本地上下文，不调用模型。不能自动读取另一个浏览器标签、跨域视频、Photoshop 或 Camera Raw 的状态。没有正文时明确显示“仅有简介”，不把元数据当作已经读过教程。

文本上下文、历史与问题合计默认硬上限 12,000 Unicode 字符，输出默认上限 1,024 token；这些是产品预算而非对任意模型窗口的保证。超限要求用户移除资料或另开会话，不静默裁剪所选正文、不自动总结。服务商仍可能因其模型限制拒绝请求，错误需明确显示。

每次最多两张图；只发送用户选定、转换为 sRGB 且去除位置等 EXIF 信息的派生图，单图最长边 1600 px、编码后不超过 2 MiB。不会上传 RAW。清楚提示图片与文字将离开本机、发送给所配置服务商；该服务商的留存政策不由站点保证。

### 7.4 回答与引用

- 有真实依据时引用上下文项编号和来源定位，站点只允许链接到这次实际提供的引用集合。
- 没有依据时标为通用解释或条件性建议，不声称是教程结论。
- 第三方原文中的指令只当资料，不执行其中要求；模型无文件、命令、浏览器或网络工具权限。
- 不从颜色词直接跳到固定滑块。涉及“蓝色更纯净”时区分当前工具、偏色/饱和度/明度问题与互补色概念。
- 不生成所谓作者真实调色过程，不自动修改本地照片或教程。

### 7.5 流式、会话与失败

前端通过本地 POST 请求接收 SSE 格式事件。每次请求绑定会话 ID、请求 ID和发送时的上下文快照。取消操作传到上游；已收到的部分回答标为中断，不伪装成完成。

401、429、超时、连接失败、协议不支持、模型不支持图片、上下文超限分别有可操作提示。保留用户问题与附件选择，不自动重试产生费用，不擅自切换服务商。切换页面不会将旧请求输出写入新会话。

## 8. 技术架构

### 8.1 组成

- 前端：React 19、TypeScript、Vite 7、Tailwind CSS 4、React Router。
- 后端：Node.js 24、Hono；生产由同一进程托管前端构建和 API，开发使用 Vite 代理。
- 存储：better-sqlite3、版本化 SQL 迁移，启用外键；无需 ORM 或云数据库。
- 图像：sharp，仅用于受支持的 JPEG/PNG 与派生图处理。
- 订阅：rss-parser；抓取、URL 安全检查和调度独立于解析。
- 凭据：macOS 钥匙串，使用已验证的本机原生绑定。
- 测试：Vitest、API 集成测试、Playwright 浏览器测试。

依赖在开发开始时验证并锁定具体版本，不因文档中的版本范围跳过原生模块兼容测试。首版不额外引入状态管理框架、向量数据库、Redis 或消息队列。

### 8.2 拟目录职责

```text
color-study/
  packages/
    web/          页面、组件、状态和可见上下文
    server/       API、数据库、文件、订阅、AI与安全边界
    shared/       只放前后端共用的数据契约和校验类型
  tests/          跨模块集成与端到端测试
  content/       经筛选的知识卡与来源种子，不包含未获权媒体
  docs/          已确认规格与实施计划
```

应用数据默认位于用户目录的 `Library/Application Support/ColorStudy`，与源码分开：SQLite、导入文件、派生图和本地设置。API Key 在钥匙串，不在此目录。测试使用独立临时目录。

### 8.3 核心实体与约束

| 实体 | 主要职责与约束 |
| --- | --- |
| Source | 订阅/教程来源、地址、许可说明、更新与失败状态 |
| FeedItem / SourceEntry | 条目与来源出现记录；规范 URL 与源内 GUID 幂等去重 |
| Tutorial | 原教程、作者、标签、版本、访问条件与可用性；不存在伪造章节 |
| TutorialSection | 实际章节/时间点、获准选段、原始定位；没有正文允许为空 |
| QualityReview | 审核范围、依据、结论、时间；不等于实际复现认证 |
| Asset / UsageRights | RAW、参考作品、教程目标、预览、用户导出与附件；保存角色、哈希、来源、许可 |
| TutorialAsset | 素材对应关系及依据；参考作品不能默认为配套原片 |
| Practice / PracticeExport | 可选练习资料、自由笔记、导出版本；不预置六个阶段 |
| KnowledgeCard | 简短知识、来源、相关工具与教程；正文为经过校验的 Markdown 数据 |
| ProviderConfig | 非敏感 AI 配置与钥匙串引用，不存 Key |
| Conversation / Message / ContextSnapshot | 页面归属、消息状态、实际发送文本与资产引用；不允许串话 |

收藏、标签按实际需要采用小型关联表，不新建泛化内容管理平台。时间以 UTC 存储、本地显示；未知不是空造的默认值。知识正文按纯内容渲染，不执行外部 MDX 或原始 HTML。

### 8.4 本地安全

仅监听 127.0.0.1 不等于免除安全措施。服务校验精确 Host，拒绝不受信的 Origin，写入与 AI 请求要求 CSRF 令牌；不开放任意 CORS。开发与生产分别使用精确允许的本地来源。

外部抓取只接受 http(s) 公网目标，校验解析后的地址和每次重定向，阻止内网、回环与云元数据地址；实际连接也需保持校验结果，不能只检查域名字符串。AI 的显式回环地址例外只存在于独立的用户配置通道。

不把 URL 路径、文件名或 HTML 直接执行。媒体 API 使用资产 ID，不接受任意磁盘绝对路径。上传限制大小并校验真实类型；文本、Markdown、RSS 与模型输出经过安全渲染。XML 禁用外部实体，不解析 DTD。

### 8.5 备份与恢复

备份包含一致性 SQLite 快照、托管资产、知识内容版本和校验清单，排除 Key、临时文件与日志。浏览器自行下载在其他目录的文件不属于备份范围；导入成为托管副本后才被包含。

恢复先在独立目录检查格式版本、文件哈希、路径和空间，不直接覆盖现有数据。用户确认后切换数据目录并保留旧目录；损坏包不改变当前状态。备份不加密时明确提醒其中可能有私人人像、笔记和聊天上下文。恢复后需重新配置 AI 凭据。

## 11. 产品验收底线

- 教程筛选、收藏、详情、资料导入和笔记可形成一条真实可用路径。
- 参考作品、配套原片和用户导出不混淆；已审核不冒充已实测。
- 本地服务保持运行、外网断开时，已有收藏、笔记和本地预览仍可使用；不可用的外部能力有诚实状态。
- 重复更新不重复入库，失败不清空收藏。
- AI 无配置仍可使用核心功能；配置后能真实请求、流式显示、取消，并正确关联页面。
- 发送前的上下文与服务端实际发送一致；无跨教程、密钥或隐私资料泄漏。
