# 调色书房：静态站点重构说明

- 日期：2026-10-28
- 状态：已实施；本地预览与浏览器验收通过
- 目标形态：GitHub Pages 静态站点，无自建服务器依赖

## 1. 为什么重做

上一版本完成了功能与安全验证，但把教程、审核、素材、订阅、AI、备份都铺在同一层。视觉上以等宽卡片和面板堆叠为主，首页没有真正的第一视觉焦点，学习路径被功能入口淹没。用户反馈的核心不是“缺功能”，而是“不像一个可用的学习站”。

这次重做只围绕三个问题：

1. 第一次打开时，知道从哪里开始。
2. 读教程、开原站、拿原片、写下自己的判断，能不能顺着走完。
3. 界面是否安静、耐看，是否让内容而不是控件占据注意力。

## 2. 设计方向

**Reading this as: a local-first photography study room for one learner, with a darkroom/editorial language, leaning toward a restrained copper accent, Geist typography, and a rail + reading column layout.**

- 深色是默认阅读环境：接近墨绿的炭黑、暖白正文、单一铜色强调。浅色主题作为“纸面”替代。
- 左侧固定资料栏（桌面）替代顶部挤满的导航；移动端使用顶部品牌条 + 底部五项导航。
- 首页使用不对称的编辑式开场：左侧主陈述，右侧“今日跟练”；下方是“读 / 练 / 问”的横向学习闭环，而不是三张等宽功能卡。
- 教程列表使用细线分隔的行，左侧色条只表示题材，不在图片上叠标签。没有无授权的摄影图，就不假装有。
- 教程详情是阅读页：来源优先，审核与许可作为正文的一部分，学习记录放在右侧小卡；移动端自然下移。
- 色彩手册把交互色轮作为唯一的大视觉，知识卡改为索引 + 可展开条目，避免 12 张同构卡片。
- 动效只用于抽屉、悬停和展开；尊重 `prefers-reduced-motion`。

## 3. 信息架构

| 路径 | 作用 |
| --- | --- |
| `/` | 今日跟练、学习闭环、继续、来源更新 |
| `/library` | 教程列表与筛选 |
| `/library/:id` | 教程阅读、来源、原片、许可、学习记录 |
| `/atlas` | HSV 色轮、分类索引、知识条目 |
| `/discover` | 来源更新、我的参考作品 |
| `/notebook` | 在学、完成、收藏 |
| `/settings` | AI 连接、主题、本地数据导入导出 |

AI 是全局抽屉，不再永久挤压内容；当前页面与选中文字作为上下文，发送前可见。

## 4. 静态架构

- Vite + React 19 + TypeScript；`base: './'`，`HashRouter`，适配 GitHub Pages 子路径。
- 教程、知识卡、初始发现数据随构建打包，位于 `packages/web/src/site/data/`。
- 个人数据存 `localStorage`：`cs:favorites`、`cs:notes`、`cs:statuses`、`cs:works`、`cs:ai`、`cs:theme`；AI Key 可在 sessionStorage 或 localStorage。
- 订阅更新由 `.github/workflows/pages.yml` 在 push / 手动 / 每日定时运行 `scripts/fetch-feeds.mjs`，只抓取标题、链接和日期，随后构建并发布。
- AI 从浏览器直连 OpenAI 兼容服务；没有服务端代理，因此可能受 CORS 限制。设置页明确提示 Key 的本地存储位置。
- 原 `packages/server` 保留为上一版本本地服务原型，不参与当前构建和运行。

## 5. 为静态托管舍弃的内容

GitHub Pages 没有服务器进程，所以以下能力不在当前版本：

- SQLite、服务端备份恢复、macOS 钥匙串；
- 在线录入/编辑教程、审核表单；
- 浏览器 RAW 统计、素材管理后台；
- 页内动态添加 RSS 来源。

这些能力仍在旧服务原型里，但不是当前交付形态。替代路径是：教程由仓库数据维护，来源由 Actions 刷新，个人记录用浏览器存储与 JSON 导入导出，AI 由用户自己的服务商提供。

## 6. 视觉验收

- 1440 px 深色与浅色首页：主标题两行内，右侧跟练卡与左侧阅读栏平衡；首页不再出现成组同构卡片。
- 教程列表：8 条数据，题材/原片筛选，右侧状态与收藏有明确位置。
- 教程详情：来源按钮是第一动作；笔记、状态和 AI 在右侧，不影响阅读正文。
- 色彩手册：色轮与索引形成主要视觉；知识条目可展开，搜索与分类联动。
- 390 / 320 px：无横向溢出；底部导航固定且不遮挡最后内容；AI 抽屉全宽。

最终检查以 Playwright 截图和真实浏览器点击为准，不以类型检查代替。
