# 调色书房

把外部摄影教程、原片入口和色彩知识整理成一个可以安静使用的学习站。它不替作者写教程，也不从前后对比图推断作者的调色流程。

本次重构为 **GitHub Pages 静态站点**：没有服务器、没有数据库托管。收藏、笔记、学习状态、参考作品和 AI 连接都留在你的浏览器里。

## 设计与页面

- **首页**：一个明确的“今日跟练”入口、学习闭环（读 / 练 / 问）、继续记录和来源更新；不是功能卡片墙。
- **教程**：克制的编辑式列表，只保留题材、工具、审核与原片状态。
- **教程详情**：先给出作者原站与配套素材入口，再说明审核依据、版权边界和你的学习记录。
- **色彩**：HSV 色相关系轮、分类索引和可展开的知识条目。
- **发现**：来源更新与“我的参考作品”；只保存标题、链接和日期。
- **记录**：在学、完成和收藏，不设置打卡或完成率。
- **AI 答疑**：右下抽屉；带上当前页面、选中文字、最近六轮和可选图片，不替代作者教程。

视觉采用暗房式深色底、单一铜色强调、Geist 字体和窄侧栏；浅色主题可在设置中切换。

## 本地运行

要求 Node.js 24 或更高。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。

生产预览：

```sh
npm run build
npm start
```

打开 <http://127.0.0.1:4317>。静态站点使用 Hash 路由，所以 `/repo/#/library` 这样的地址不依赖服务器重写。

## 部署到 GitHub Pages

1. 把仓库推到 GitHub，默认分支为 `main`。
2. 在仓库 Settings → Pages 选择 **GitHub Actions**。
3. `.github/workflows/pages.yml` 会在 push、手动触发和每天定时执行：
   - 抓取摄影来源的标题、链接与日期；
   - 构建 `packages/web/dist`；
   - 发布到 GitHub Pages。
4. 站点可以在 `https://<user>.github.io/<repo>/` 下运行，`base: './'` 和 HashRouter 已适配子路径；自定义域名同样可用。

订阅源在 `scripts/fetch-feeds.mjs` 中配置。抓取失败时保留仓库里的种子数据，不会让构建失败。图片版权未确认，因此只发布元信息，不下载图片。

## AI 连接

设置 → AI 连接中填写 OpenAI 兼容的 Base URL、模型和 API Key：

- 请求从浏览器直接发给你配置的服务商，不经过 GitHub。
- 不勾选“记住 Key”时，Key 只放在 `sessionStorage`，关闭标签页即消失；勾选后才写入本机 `localStorage`。
- GitHub Pages 上没有服务端代理。若服务商不允许浏览器跨域直连（CORS），请填写你自己部署的代理地址。
- 图片附件会在浏览器内缩放、重编码并去掉元数据；RAW 不支持发送。
- 这是一份个人学习工具。公开站点上的 Key 只属于当前浏览器，但共用电脑时请不要勾选记住。

## 本地数据

收藏、笔记、状态、参考作品和 AI 配置保存在浏览器的 localStorage。设置页可以导出/导入 JSON，JSON 不包含 API Key。清理浏览器站点数据后记录不会自动同步。

## 内容与审核

- 8 条教程：风光 3、人像 3、通用工具 2。
- 3 条有配套原片：PHLEARN 两条风光课程（需免费账户）和 Tutvid 的人像 DNG（作者公开直链，已核实文件签名）。
- 12 张有来源的知识卡，来源以 darktable、Krita、GIMP 官方文档为主。
- 12 条初始来源更新，来自 SLR Lounge、Photoshop Essentials 与 Light Stalking；由 Actions 每日刷新。

教程审核基于公开正文与来源页面，**没有观看完整视频、没有逐课重做复现**。审核记录不是“实测可复现”认证；软件版本、素材和作者流程请回到原站确认。

## 命令

```sh
npm run check       # TypeScript
npm run build       # 静态站点构建
npm run fetch:feeds # 手动刷新来源快照
npm run test:e2e    # Playwright：静态页面、本地记录、静态 AI（本地 CORS 模拟服务）
npm test            # 数据完整性 + 旧本地服务原型的单元/集成测试
```

## 范围说明

静态版保留教程、色彩、发现、记录和 AI；不包含需要服务器的 SQLite、macOS 钥匙串、备份恢复、素材管理后台、浏览器 RAW 统计和在线教程录入。`packages/server` 是之前的本地服务原型，当前静态站点不启动它。

## 已知限制

- AI 真实供应商兼容性需要你用自己的 Key 验证；CORS 是最常见的问题。
- 订阅只支持配置在仓库脚本里的 RSS/Atom，不在页面内动态添加来源。
- 作品条目只保存元信息和自己的观察，不复制图片，也不代表作者的真实后期流程。
- 站点使用 Hash 路由，分享链接会带有 `#/`。
